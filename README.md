## 第五人格钢琴家具自动演奏工具
本项目是一个基于Godot4引擎制作的工具，依赖于安卓的无障碍权限模拟点击屏幕，实现钢琴家具自动演奏。
### 使用方法
1.下载构建好的APP并给予无障碍权限（每次重启软件需要重新给予权限，这是安卓的机制）
2.在游戏内打开钢琴界面，截图，并导入APP，微调每个按键的位置
3.在网上下载Midi文件并导入APP
4.APP切换到小窗模式，进入游戏的钢琴页面，在APP中点击播放歌曲，并将APP变为最小小窗
5.享受自动演奏

### 注意事项
1.由于钢琴家具的音域不全，实际演奏可能与原曲有误差，导入时显示的命中率越高，误差越小
2.安卓的模拟点击有限制，对于长时间多指点击的部分可能会漏音
3.部分安卓系统在特定情况下可能会导致手机重启，若您的系统存在此问题，请升级最新版本并向手机厂商客服反馈（主包反馈之后荣耀的MagicOS已修复此问题）
